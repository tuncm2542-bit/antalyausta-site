  # README Dosyasını Ekleme Adımları  
 
  1. Butona Tıklayın: Ekranın alt kısmında gördüğünüz yeşil "Add a README" butonuna basın.  
  2. Metni Yapıştırın: Açılan düzenleme ekranındaki boş kutucuğa, aşağıda sizin için tekrar hazırladığım metni kopyalayıp yapıştırın:  
 
  ```markdown  
  # Proje Adı: Web Projesi Başlangıcı  
 
  Bu depo, temel bir web projesi olan `index.html` dosyasını içermektedir. Proje, web geliştirme sürecine giriş yapmak ve temel HTML yapısını sergilemek amacıyla oluşturulmuştur.  
 
  ## İçerik  
  - index.html: Projenin ana yapısını oluşturan temel HTML dosyası.  
 
  ## Özellikler  
  - Basit ve temiz HTML yapısı.  
  - Web tarayıcılarında doğrudan görüntülenebilir.  
  - Geliştirmeye ve yeni özellikler eklemeye uygun altyapı.  
 
  ## Nasıl Çalıştırılır?  
  1. Depoyu Klonlayın:  
 `git clone https://github.com/tuncm2542-bit/proje-adi.git`  
  2. Dosyayı Açın:  
 İndirdiğiniz klasör içerisindeki `index.html` dosyasına çift tıklayarak herhangi bir web tarayıcısında görüntüleyebilirsiniz.  
 
  ## Lisans  
  Bu proje MIT Lisansı altında açık kaynaklıdır.  
  ```  
 
  3. Kaydedin: Metni yapıştırdıktan sonra sayfanın en altına inin ve yeşil renkli "Commit changes..." butonuna tıklayın. Ardından açılan küçük pencerede tekrar "Commit changes" butonuna basarak işlemi onaylayın.
